# Media Downloader Bot

Telegram-бот для загрузки видео и аудио из интернет-источников (YouTube и др.).

## Возможности

- Загрузка видео с выбором качества (360p–1080p, лучшее)
- Загрузка аудио с выбором битрейта (128–320 kbps)
- Форматы: MP4, MKV, WEBM (видео); MP3, M4A, OPUS, WAV, FLAC (аудио)
- Субтитры: отдельный файл или вшитые в видео (SRT, VTT, ASS)
- Плейлисты: загрузка всего плейлиста или выбор диапазона
- Очередь загрузок с прогресс-баром и отменой
- Пользовательские настройки (сохраняются между сессиями)
- Админ-панель: статистика, активные загрузки, контроль диска
- Автоматическая очистка временных файлов

## Установка

### Локальный запуск (Windows)

1. Установите Python 3.11+ и FFmpeg
2. Создайте бота через @BotFather и получите токен
3. Настройте окружение:

```bash
cd media-downloader-bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

4. Создайте `.env`:

```bash
cp .env.example .env
# Отредактируйте .env, вставьте BOT_TOKEN
```

5. Запуск:

```bash
python main.py
```

### Docker

```bash
docker-compose up -d
```

## Команды

| Команда   | Описание                          |
|-----------|-----------------------------------|
| /start    | Запуск бота, главное меню         |
| /help     | Инструкция по использованию       |
| /settings | Настройки пользователя            |
| /cancel   | Отмена текущей операции           |
| /admin    | Админ-панель (только для админов) |

## Конфигурация (.env)

| Переменная               | Описание                              |
|--------------------------|---------------------------------------|
| BOT_TOKEN                | Токен бота от @BotFather              |
| DATABASE_URL             | URL базы данных                       |
| DOWNLOAD_DIR             | Папка для загрузок                    |
| TEMP_DIR                 | Временная папка                       |
| MAX_CONCURRENT_DOWNLOADS | Лимит одновременных загрузок (глоб.)  |
| MAX_USER_QUEUE           | Лимит задач на пользователя           |
| TELEGRAM_FILE_LIMIT_MB   | Лимит размера файла для Telegram      |
| ADMIN_IDS                | Telegram ID администраторов           |
| FFMPEG_PATH               | Путь к FFmpeg (пусто = из PATH)       |
| LOG_LEVEL                | Уровень логирования                   |

## Стек

- Python 3.11+
- Aiogram 3.x (Telegram Bot API)
- yt-dlp (медиапарсер)
- FFmpeg (обработка медиа)
- SQLAlchemy + SQLite/PostgreSQL
- asyncio

## Безопасность

- Токен хранится в .env, не в коде
- URL валидируется перед обработкой
- Имена файлов санитизируются
- Временные файлы автоматически удаляются
- Лимиты параллельных загрузок
- Проверка размера файла перед отправкой

## Важно

Бот предназначен для загрузки контента, на который у вас есть права или разрешение на сохранение. Соблюдайте условия использования соответствующих платформ.
